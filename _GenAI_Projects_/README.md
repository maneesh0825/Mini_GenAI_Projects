## Installation

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd ML_AI_Projects
pip install -r requirements.txt
```

For spaCy:

```bash
python -m spacy download en_core_web_sm
```

## How to Use

Each numbered folder is an independent project.

Example:

```bash
cd 01_Linear_Regression
python main.py
```
